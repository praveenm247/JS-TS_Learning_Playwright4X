# JavaScript, TypeScript, and Playwright Learning

A hands-on repository for learning JavaScript fundamentals and building toward TypeScript and Playwright.

## Lessons

### JavaScript basics

`01_Chapter_JS_Basics/` contains introductory examples:

- `01_helloworld.js` prints a Hello, World! message.
- `02_arithmaticoperation.js` demonstrates basic arithmetic operators.

### JavaScript keywords and identifiers

`02_Chapter_JS_Keywords_Identifiers/` contains examples covering:

- JavaScript engine and `let` behavior
- Keywords and identifier naming rules
- Comments
- Identifier interview questions

## Run an example

Run an individual JavaScript file with Node.js from the repository root:

```sh
node 01_Chapter_JS_Basics/01_helloworld.js
```

Change the path to run another example. Each lesson is a standalone script.

## Learning path

Work through the numbered chapter folders and run the examples as you go. New lessons will build from JavaScript fundamentals toward TypeScript and Playwright.
